# Image Operations with OpenCV

A notebook that practises basic image processing with OpenCV on a sample image.

## What it covers

- Reading an image and checking its data type and size
- Converting colour to grayscale, and BGR to HSV
- Geometric transforms: rotation, mirroring and more

## Built with

Python, OpenCV, NumPy, Matplotlib.

## How to run

```bash
pip install opencv-python numpy matplotlib
```

Open the notebook in Jupyter (or VS Code) and run the cells from top to bottom.
